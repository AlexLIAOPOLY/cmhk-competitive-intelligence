# 业绩摘要生成

业绩摘要只在用户或报告生成入口触发时启动一个独立的整理 Agent。券商观点按本次摘要需要联网收集，不由本模块建立每日采集任务。

1. 读取正式数据库，保存本份报告使用的数据快照。
2. 按公司检查缺项和时效。同一公司缺少的财务字段合并搜索；券商观点、市场反应分别检索。
3. 财务补充使用公司官网或交易所原文；券商、财经媒体及其他公开观点须在后台核验记录保留来源和日期。核对公司、来源日期、字段和数字；确实没有可靠依据的项目写为“-”。行情日期和券商评级日期分别保留。
4. Agent 根据这份事实包整理正文。已有近期财务数值、正负号、原币种和报告期间不由模型改写；如果本轮发现晚于库内已知来源日期的官方业绩公告，则复用该公告重新核对相关财务字段。新信息须引用该公司对应字段的原文；各公司继续保留实际财年口径。
5. 用原 Word 模板输出同样的六列汇总表、十家公司和五项摘要，并生成 PDF 预览与同名质量审计。
6. Word 和预览生成后立即进入对应语音生成；文件内容哈希用于确认音频与报告版本一致。语音失败自动重试一次，并明确报告未完成状态。

## 独立边界

- 执行入口：`generate_carrier_performance_report.py`；整理模块：`cmhk/reporting/performance_agent.py`。
- 不触发六 Agent 日常研究、新闻爬取、飞书镜像同步或订阅发送，不写回四库。
- 每份报告独立保存到 `var/performance_reports/<时间与唯一标识>/`：`database.json`、`searches.json`、`inputs.json`、`drafts.json`、`audit.json`、`model.json`。
- 搜索最多三路并行；一个报告 Agent 逐家公司整理，单次模型请求有总等待上限。模型输出不完整时重试一次，对原文充分但未通过的字段最多修正一次。失败字段与错误写入该份报告的审计，不伪造“未公开披露”或完整成功。
- 页面中的业绩摘要与爬虫互不锁定；周报原有规则保持不变。
- 单独验收可使用 `--output <独立路径.docx>`；该模式不进入正式报告目录和归档，PDF 也写在该输出目录内。
- 已保存的事实包和模型稿可通过 `finalize_model` 重新核验，并传给 `render_report(model=...)` 重排原模板，无须重新检索十家公司。补查来源、原始运行及已解决的失败尝试须保留在审计中，不能将重排时间冒充资料发布日期。

## 版式约束

保留 `carrier_performance_template.docx` 原文件。生成稿按用户要求去掉部门副标题和开篇说明段，主标题之后直接进入汇总表。中文沿用原版仿宋：主标题20磅、表题与公司标题16磅、正文14磅、表格12磅；保留原有粗体层级、编号、页脚、主题和段落样式。汇总表继续使用“主体、最新披露、收益、EBITDA / 利润、资本开支、派息”；正文保持原公司顺序及派息、资本开支、战略升级、券商观点、市场反应五项。

填入表格时须保留模板的段落及文字属性，并明确指定仿宋，避免 `cell.text` 清空字体后回落到默认字体。本机转换业绩摘要 PDF 时，读取已安装 Microsoft Word 自带的仿宋字体目录，不安装字体或改变全局设置。验收既要与旧版实际 Word 文件对照，也要检查 PDF 实际使用的字体并逐页看图；仅比较 styles、fontTable 等文件不能证明最终字体正确。

正文按旧模板直接写业务内容，不插入“据某网站”、来源括注、链接或出处说明。券商名称、实际评级日期、评级、目标价、行情时间和财务比较口径属于正文信息，须保留；非券商评论写为“公开评论认为”，不冒充机构评级。来源 URL 与原文继续保留在研究记录；兼容旧稿时移除的出处说明及修改前后文字保存到同名质量审计的 `sourceAttributionEdits`，不在正文或附录重复展示。

表格只保留期间、金额、单位、每股派息或原文明确的同比变化，详细解释放在正文；财年和数值相邻时不得把金额误识别为年份。资本开支或派息的首句有充分依据、仅后续附加金额或日期未通过时，首句仍须经过同一证据检查，审计记录删去附加说明的原因。

## 预览与语音

新报告可直接单击文件名预览，再次单击取消；双击文件名编辑名称。报告归类支持当前文件列表的元数据，避免后台摘要缓存稍晚更新时新文件点击无反应。

语音同时读取同一份 Word 的业绩汇总表与正文，使用适合收听的完整句子和自然衔接，不朗读“结论：”“摘要：”等标题标签，不逐项播报缺项或网址，也不能将摘要缺项说成公司未披露或风险。播放器沿用应用深蓝底、青色控件和清晰字幕，支持键盘焦点、进度拖动和窄屏布局。

业绩摘要中的数字展开为口语后，按完整句子分成约360字符一段生成，再统一声道、音量和语速后合并。发布前用真实语音识别核对全文、最后48个有效字符以及每句字幕，阻止“时长足够但结尾未播完”的文件标成成功。此分段上限和完整性检查仅用于业绩摘要，周报保持原来的生成配置。音频下载入口支持HTTP字节范围，暂停时点击进度条也能定位到对应音频和字幕；参考 [MDN范围请求说明](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests)。
