# 六 Agent 全流程效率验收 · 2026-09-09

## 范围与结论

保持任务分配 → 六个研究 Agent → 单个最终审核 → 单个四库写入 → AI 洞察 → 页面发布的现有架构。保留41家公司、473项指标、全部历史基线与官方原文、完整性和事实校验、失败记录及增量晋升规则。

本次削减重复查询、重复输入和重复解析，优化网络等待；没有减少模型决策预算、跳过最终审核或将缺失证据标记为成功。

## 实际瓶颈

- `research_20260908_rerun_074509` 截至归档最后事件记录1,625次模型响应、18,625,435个供应商报告 Token，其中输入17,501,963个，约94%。该轮曾被停止，不能将此数当作完成整轮的固定成本。
- `research_20260909` 截至10:53:36记录989次模型响应、11,219,132个 Token，其中输入10,566,523个。最终审核尚未完整结束；完成指标处理不代表资料已齐。
- 同指标族生成相同搜索词，仍多次请求；不同指标重复发送同页预览与历史基线字段。
- 正则 `.{1,1100}(?:\s|$)` 在超长无空格文本上反复回溯，且每个指标再次对整页分段。隔离归档重放的进程采样确认 CPU 消耗集中在该正则扫描。

## 各阶段处理

| 阶段 | 优化或保留的机制 |
| --- | --- |
| 任务分配 | 保留原六组与逐项任务合同；不减少公司或指标。 |
| 搜索 | 同一次公司收集中相同查询复用成功结果；空结果保留再次请求机会，跨轮与最终补查重新搜索。 |
| 原文读取 | 独立请求并行；每组最多3个 I/O 线程，全进程最多6个网络请求。父页面完成后才选择后续公告，维持原排序与数量。 |
| 证据整理 | 线性分段保持旧正则的文本、编号、偏移；仅在原文逐字相同时复用解析索引。 |
| 模型提交 | 基线用紧凑表格表达，重复预览引用已有相同预览；保留每条期间、值、单位、口径、URL及全文读取工具。 |
| 最终审核 | 复用同一优化后的收集与提取代码，保持单个审核 Agent、独立联网补查与逐项检查点。 |
| 四库写入 | 已有同轮隔离、增量合并与幂等门禁保留；不通过减少校验来提速。 |
| AI 洞察 | 已有证据哈希和格式版本缓存保留；证据变化仍使对应完整分析失效，规则回退不冒充模型成功。 |
| 页面发布 | 数据重建、发布、外部回读保留。没有新事实时已有的不重复生成机制继续生效。 |
| 新闻相关流程 | 已核查语义审核、新闻筛选和洞察的持久化检查点与输入版本缓存；本次未改动这些独立业务规则。 |

## 验收证据

- 41家公司使用同一归档搜索/页面响应重放：原568次搜索请求变为481次，减少87次（15.3%）；535次页面读取保留。逐公司搜索记录、页面选择和原文结果完全一致；新增复用与耗时字段另行比较。
- 41家公司、473项指标的旧版/新版初始用户输入逐项重放并解包比对，全部内容一致；合计14,953,575字符降为13,777,624字符，减少1,175,951字符（7.86%）。这里仅统计初始用户上下文，不含系统提示、工具协议或后续模型轮次，不等同于整轮 Token 节省。
- 原文分段边界、超长文本、中文文本与旧正则结果一致；页面内容变化及官方资格失效会清除缓存。零值、空值、布尔值、浮点数与不同字段结构不被合并。
- 超长文本 CPU 微基准：20,000字符无空格前缀加报告文本，旧正则0.257339秒，新扫描0.000014秒，片段结果完全一致。这个局部比例不能外推为整轮提速比例。
- 真实网络抽查 SK Telecom：3条搜索、11个页面，11个官方原文读取成功。总用时29.09秒；请求各自耗时合计77.971秒，资料收集阶段28.499秒。没有模型调用、飞书写入或数据发布。并行请求耗时总和不是串行 A/B 实测。
- 真实内部模型小样本：SK Telecom 收入在旧输入、压缩输入及最终格式说明下均一次提交相同已核验结果（Q2 2026、KRW 4.3591 trillion）。中国移动收入的旧输入达到2次隔离调用上限仍未提交；压缩输入一次提交 `no_update`。这些样本不能证明473项整轮质量或固定节省比例。
- 网关在输入变动后仍可能重复返回相同 usage 和内容，且小样本耗时受缓存、速率限制与服务负载影响。因此不把这些响应耗时或字符减少直接宣称为计费 Token 节省。
- 162项回归通过：研究、截断恢复、原文校验、最新披露、最终审核、增量写库和前端数据交付。修复了一条旧测试的输入夹具：无新披露的测试现在明确已完成最终审核，避免把缺少计划的半成品当完整运行；生产审核未被绕过。
