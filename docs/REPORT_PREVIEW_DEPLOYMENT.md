# 报告预览与正文编辑部署

报告在浏览器内编辑正文，服务端保留 DOCX 结构、历史备份并重新生成 PDF。阅读状态展示 PDF；访问者无需安装 Word、LibreOffice、插件或桌面编辑器。

统一部署入口为仓库 Dockerfile（Render 蓝图亦使用此镜像）。镜像包含 `libreoffice-writer` 和中文字体，使用无界面的 `soffice --headless` 转换。镜像启动命令保持原有飞书初始化和 Python Web 服务。转换代码没有 Microsoft Word、AppleScript 或桌面唤起回退路径。

直接在已有非容器主机运行 Python 时，主机管理员需提供服务端 `soffice` 命令和中文字体；这不是访问者的安装要求。转换器缺失或失败时，正文保存成功但明确提示 PDF 未生成，不显示过期 PDF 为新结果。

现有有效 PDF 直接展示。修改后 PDF 由服务端重新排版；DOCX 段落、表格、页眉页脚结构保留，但不同转换引擎或缺失字体仍可能产生换行、分页差异，不能承诺与另一引擎产物逐像素一致。服务器与本地使用相同镜像及字体可减少差异。

macOS 无界面转换显式读取主机已有系统字体目录，避免新版转换器漏读中文字体；不安装或更改用户字体。Linux 镜像使用镜像中既有的 Noto CJK/文泉驿字体及系统 fontconfig。
