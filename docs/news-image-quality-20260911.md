# 战略新闻配图修复（2026-09-11）

用户要求：推送的每条新闻都必须有相关图片；原文没图时由 Agent 按具体新闻关键词联网补图；广告图过滤写入 skill，反复测试，并更新所有账户的新闻。

## 实现

- 原文 Article/NewsArticle、正文及懒加载图片优先；og:image/twitter:image 仅为候选。
- 原文无合格图时，文本 Agent 生成具体主体/事件查询，检索网页及图片并打开出处页。支持真实相关资料图，分类及出处只保存在后台；按用户后续要求，所有配图均不显示图注，新闻原文链接不变。
- 过滤广告/推荐区、其他文章链接、图标/横幅/占位图。Qwen 视觉模型实际看图，要求可见内容、来源依据、相关性分类及置信度，拒绝栏目封面、促销及不相关活动照片。
- 审核与上传使用同一图片字节，保存 SHA-256、图片/出处 URL、模型、技能版本、判定和关键词。旧缓存失效；失效接口、超时、截断等保留批次与检查点重试。
- 正式结构化新闻卡片构建前逐条检查合格图片；自动、人工、重试和分卡共用此关卡。已发送或发送结果不明的回执保留原请求与幂等键。
- 规则：`cmhk/skills/cmhk-strategic-news-push/SKILL.md`；代码：`cmhk/services/news_image_quality.py`、`news_delivery_assets.py`、`news_delivery_guard.py`。

## 自动流程恢复

- 素材元数据超过 10 分钟刷新时，保留同一新闻原文已发现的候选，再按当前规则审核，防止长队列丢失已找到的正文图。搜图中断也保留已访问页与候选；查询耗尽后延时更换具体关键词，不长期重复无效查询。原文英文路径作为额外查询，不挤掉主体资料图查询；错误关键词结果不进入成功模型缓存。
- 去重遇不完整格式或矛盾结果，切为逐条审核并保存进度；长历史按每段最多 8 条全部比较。先比较相关历史段但不减少范围；确认重复须有两边逐字证据，保留新闻须完成全部历史段审核。模型逐条返回直接对象，引用只能选择原文证据选项，避免数组转义和引号改写。已通过条目单独保存，不因同批另一条失败而重跑。失败不跳过审核，也不删稿凑成功。
- 摘要整批输出若反复返回错误 JSON 结构，改为逐条真实模型生成，保持原事实、顺序和条数；已完成条目按完整来源证据复用。错误字符串不自动修补成文案，也不伪造缺失内容。
